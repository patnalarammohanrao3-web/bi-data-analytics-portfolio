# BI & Data Analytics Project Roadmap

A curated catalogue of 100 practical project ideas spanning SQL, Power BI, Tableau, Snowflake, Python, data engineering, DevOps, business analytics, and applied AI.

> **Transparency:** These are project ideas and repository naming suggestions, not 100 completed projects. Build each project, document the methodology, and publish only work you have actually completed. Use public or synthetic datasets. Never upload employer-confidential code, data, credentials, or screenshots.

## How to use this roadmap

1. Choose a project that matches a skill you want to demonstrate.
2. Create its repository or add it as a folder in a portfolio repository.
3. Include source code, sample data or dataset instructions, screenshots, tests, and a clear README.
4. Record assumptions, limitations, and reproducible setup steps.
5. Mark a project complete only after the work is genuinely implemented and reviewed.

## Project quality checklist

- [ ] Clear problem statement and intended audience
- [ ] Public or synthetic data with source and license noted
- [ ] Reproducible setup and execution instructions
- [ ] Readable, tested code and meaningful commit history
- [ ] Data model, assumptions, and metric definitions documented
- [ ] Screenshots or sample outputs that do not expose private data
- [ ] Limitations and next steps explained

## Responsible portfolio practices

This repository is a roadmap, not evidence that all listed projects have been implemented. Listing an idea does not mean it has users, downloads, or measurable impact. Do not represent planned work as completed work or claim organization-owned work as personal open-source contributions.
